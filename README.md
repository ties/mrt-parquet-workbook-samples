# Example workbooks for MRT-parquet files

These example workbooks are made to accompany a presentation on parquet files 
that contain MRT BGP data.

Run the workbook by running
```
uvx --python 3.14 marimo edit --sandbox workbooks/prefix_histogram.py
```

  * `uvx` is the `uv` - a pip alertnative - version of `pipx`
  * `marimo` is the tool to run marimo workbooks, an alternative to jupyter  
     workbooks.
